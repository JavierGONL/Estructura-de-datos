\section{requerimientos basicos de la implementacion}
\label{sec:metodologia}

Esta seccion se enfoca en los requerimientos mas basicos que debe cumplir el codigo.
\\
Para cumplir con la idea planteada el proyecto debe ser capaz de:

\begin{itemize}
 \item Leer cada uno de los archivos del conjunto de datos MIT (.head, .dat, .atr y .xws)
 \item Organizar los datos de manera que puedan ser facilmente leidos y manejados por las estructuras de datos
 \item Graficar los datos de manera que sean entendibles
 \item Filtrar ruido para obtener mejores resultados en las propiedades de la señal.
\end{itemize}
